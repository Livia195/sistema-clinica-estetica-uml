# Sistema de Agendamento para Clínica de Estética

## Descrição
Projeto desenvolvido para a disciplina de Análise Orientada a Objetos e Projeto Arquitetural.

O sistema tem como objetivo realizar o gerenciamento de agendamentos de uma clínica de estética, permitindo o controle de clientes, profissionais, procedimentos, pagamentos e atendimentos.

---

## Diagramas Desenvolvidos

- Diagrama de Casos de Uso
- Diagrama de Classes
- Diagrama de Sequência
- Diagrama de Estados
- Diagrama de Componentes
- Diagrama de Implantação

---

## Funcionalidades Principais

- Cadastro de clientes
- Cadastro de profissionais
- Cadastro de procedimentos
- Agendamento de atendimentos
- Cancelamento e remarcação
- Controle de agenda
- Histórico de atendimentos
- Pagamentos
- Avaliações
- Notificações automáticas
